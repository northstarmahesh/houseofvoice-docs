Welcome to the House of Voice API documentation. Our API allows you to programmatically interact with the House of Voice platform, enabling you to create and manage leads, schedule calls, and more.

## Base URL

All API requests should be made to the following base URL:

```
https://login.houseofvoice.ai/api
```
